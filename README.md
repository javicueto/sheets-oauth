# sheets-oauth

A personal Google OAuth client. It exists so that tooling running on my own Mac
can read and edit **my own** Google Sheets through the Google Sheets API,
instead of me doing the same edits by hand in a browser.

It is not a product and not a service. It has no users other than me, no server,
and no backend.

- **Owner:** Javier Cueto
- **What it accesses:** Google Sheets, on the account that authorises it
- **Where it runs:** locally, on one laptop
- **Privacy policy:** [PRIVACY.md](PRIVACY.md)

## Why this repository exists

Google requires a homepage and a privacy policy URL before an OAuth app can be
moved out of testing mode. Those two pages are the entire contents of this
repository — there is no code here.
